# Power-measurement-board-usingESP32S3-Microcontroller

ESP32-S3 Power Measurement Board

A KiCad-based power-measurement board design intended to monitor the
voltage and current generated by a photovoltaic (PV) panel. The design
uses an INA239 power-monitoring IC to acquire measurement data, an
ESP32-S3 microcontroller for processing, and Bluetooth Low Energy (BLE)
as the intended wireless link to a mobile device.

  Project status: Design and firmware files are included. The PCB has
  not been physically manufactured or assembled, and hardware testing
  has not been performed. Therefore, measurement accuracy, electrical
  performance, SPI communication, and BLE data delivery have not been
  validated on physical hardware.

Project overview

The project was developed as a project seminar at Hochschule Wismar. Its
objective was to design a power-measurement board in KiCad and develop
ESP32-S3 firmware for communicating measurement data to a mobile device.

Design objectives

-   Design a custom power-measurement PCB using KiCad.
-   Interface the INA239 measurement IC with an ESP32-S3 over SPI.
-   Include digital isolation between the measurement and
    microcontroller sections.
-   Develop ESP32-S3 firmware for measurement-data handling.
-   Implement a BLE service and characteristics for wireless
    communication with a mobile device.

Hardware design

The project includes KiCad schematic and PCB design files. The circuit
concept routes the measurement signals to the INA239, then uses a
digital communication path with isolation between the measurement
circuitry and the ESP32-S3.

The design files are provided for review and further development:

-   POWER MEASUREMENT BOARD.kicad_sch — schematic source.
-   POWER MEASUREMENT BOARD.kicad_pcb — PCB layout source.
-   POWER MEASUREMENT BOARD.kicad_pro — KiCad project settings.
-   Gerber file.zip — manufacturing plot exports.

PCB note: The supplied PCB file contains front- and back-copper layers
(F.Cu and B.Cu), so this design should be described as a two-layer PCB.

Firmware

The repository includes an ESP32-S3 firmware source file. The source
uses the Arduino framework and includes libraries for SPI and BLE.

The firmware currently contains code intended for:

-   BLE server initialization and advertising.
-   BLE service and TX/RX characteristic creation.
-   SPI command routines for communication with the INA239.
-   Handling of measurement-ready interrupt logic.
-   Formatting measurement-related values for BLE notification.

Firmware status: The included source is a development version and has
not been validated on assembled hardware. SPI readback, register
addresses and command framing, pin assignments, interrupt handling,
measurement scaling, and BLE payload handling require review and
verification before the firmware can be considered functional. Do not
treat the presence of these routines as proof of successful measurement
acquisition or wireless transmission.

Recommended next steps

1.  Run ERC on the schematic and resolve all relevant electrical-rule
    issues.
2.  Run DRC on the PCB and review clearances, widths, connectivity and
    manufacturing constraints.
3.  Verify footprints, pin mappings, connector assignments and component
    ratings against datasheets.
4.  Recheck the shunt-resistor value, power rating and INA239
    calibration/configuration.
5.  Review the SPI implementation, including bus initialization,
    chip-select handling, register addresses, readback and data types.
6.  Review interrupt handling and ensure shared interrupt state is
    handled safely.
7.  Manufacture and assemble a prototype only after design review.
8.  Perform staged bring-up with current-limited supplies and suitable
    test equipment.
9.  Record measured results, test conditions, instrument details and any
    deviations.
10. Validate BLE notifications and the mobile-device interface after
    hardware communication is confirmed.
